# Hotel Booking Cancellation Analysis

## Project Overview
This project analyzes hotel booking data to identify key factors influencing booking cancellations. The analysis helps hotels understand customer behavior, booking trends, and cancellation patterns to improve revenue management and customer retention.

## Objectives
- Analyze hotel booking cancellation trends
- Identify factors affecting cancellations
- Study customer booking behavior
- Discover seasonal booking patterns
- Provide actionable business insights

## Tools & Technologies
- MS Excel
- Pivot Tables
- Pivot Charts
- Data Cleaning
- Dashboard Creation

## Key Features
- Data Cleaning and Transformation
- Cancellation Rate Analysis
- Customer Segment Analysis
- Booking Source Analysis
- Interactive Excel Dashboard

## Results
- Identified major reasons for booking cancellations
- Analyzed seasonal booking trends
- Evaluated customer booking behavior
- Created an interactive dashboard for business decision-making
